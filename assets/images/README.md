# Air-Mesh image assets

The Air-Mesh triangle mark is the primary product identity and is intentionally reused across the launcher, splash, web, and Android adaptive-icon slots.

| File | Runtime role |
|---|---|
| `icon.png` | Expo app icon and primary brand mark. |
| `splash-icon.png` | Splash-screen mark. |
| `favicon.png` | Web favicon. |
| `android-icon-foreground.png` | Android adaptive-icon foreground. |
| `android-icon-background.png` | Android adaptive-icon background. |
| `android-icon-monochrome.png` | Android monochrome launcher variant. |
| `mesh-network-reference.png` | Educational topology visual used in About; it is not live network state. |

Keep these files square and aligned with the paths in `app.config.ts`. Do not replace the logo with a screenshot or a runtime-generated placeholder.
